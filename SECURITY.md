# Política de Segurança

## Limites do protótipo

Este projeto é uma demonstração estática. Não utilize a autenticação de
interface, o armazenamento local ou os dados de exemplo como mecanismo de
segurança em produção.

## Reporte responsável

Não publique chaves, senhas, dados pessoais ou detalhes exploráveis em issues
públicas. Encaminhe o reporte de forma privada ao responsável pelo projeto.

## Antes de publicar

- remova dados de demonstração e credenciais locais;
- implemente autenticação e autorização no servidor;
- proteja dados, logs e exportações;
- mantenha segredos fora do repositório.
